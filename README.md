# Portfolio

A personal portfolio site built with React and Vite.

## Features

- Fast development with Vite HMR
- React component-based UI
- Minimal, modern front-end setup

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open the local URL shown in the terminal to preview the site.

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

## Project structure

- `src/` — React app source files
- `public/` — static assets
- `index.html` — Vite entry HTML
- `vite.config.js` — Vite configuration

## Notes

This repository is intended as a personal portfolio or showcase site. Customize the components under `src/components/` and the main app styling in `src/App.css`.
